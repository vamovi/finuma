# tami · marca

Rama solo con los elementos de la marca tami (dirección de lettering Ritmo, elegida).

- `brand/tami/`: exploración de lettering (Puente, Ritmo, Eco).
- `brand/tami/kit/`: brand kit de Ritmo: logotipo en SVG (`logo/`), lámina de logotipo, paleta, tablero y aplicaciones. Reglas de uso en `brand/tami/kit/README.md`.
- `styles/tami.css`: colores como variables CSS (verde `#173A2B`, coral `#F27B75`, blanco `#FFFFFF`).
- `scripts/`: `dibujar_logo_tami.py` (SVG del logotipo), `generar_lettering_tami.py` y `generar_kit_tami.py` (API de imágenes de OpenAI, requieren `OPENAI_API_KEY`).

Las imágenes generadas son propuestas conceptuales. El logotipo SVG es un primer dibujo vectorial y necesita ajuste óptico antes de la entrega final.
