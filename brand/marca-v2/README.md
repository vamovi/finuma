# Marca Finuma · Versión 2 · Punto en la i

Alternativa a `brand/marca/` con el mismo brief (`finumabrief.md`), la misma paleta y la misma tipografía (Outfit). El avatar circular no usa la «f».

Logotipo «finuma» en Outfit Bold verde, con el punto de la i en coral intenso. Avatar: una «i» crema con el punto coral sobre círculo verde (sin «f»). El punto se usa como marcador: viñeta de datos clave, cuota actual y cierre de titulares. Idea: información clara.

Paleta: Verde #173A2B (titulares, botones, pie) · Tinta #14281F (texto) · Coral #F27B75 (banda de acento) · Coral intenso #EA6662 (punto, barras de requisitos) · Crema #F9F9F7 (fondo) · Línea #D9DBD6 (separadores).

Riesgos: El avatar puede leerse como el ícono universal de «información». Eso refuerza la idea de claridad, pero lo hace menos propio.

Archivos: `logo.png` (logo, variantes y avatar a 96/48/32/20 px), `tablero.png`, `aplicaciones.png`. Regenerar: `python3 scripts/generar_marca_versiones.py v2`.
